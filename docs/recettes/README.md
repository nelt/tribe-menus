# Plans de recette

Un plan de recette par version, `vX.Y.Z.md`, écrit dans la PR de release d'après [`_template.md`](_template.md) : analyse des changements et des risques, voie de preuve de chaque changement, points de contrôle de la vidéo, séance manuelle, puis résultats. Procédure : [`docs/recette.md`](../recette.md) (ADR 0032).

Le plan de recette est la seule trace de la recette : les vidéos des parcours automatiques sont supprimées quand elle est terminée.

| Version | Plan de recette | Statut |
| --- | --- | --- |
| `v0.6.0` | [`v0.6.0.md`](v0.6.0.md) | analyse proposée |

Les recettes de `v0.1.0` à `v0.5.0` sont antérieures à cette procédure : leurs séances sont décrites dans les plans `recette`, `bibliotheque`, `planning`, `courses` et `grands-ecrans`.
